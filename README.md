# 一种解决《原神》清籁逐雷记系列任务解谜问题的算法
用代码解决《原神》清籁逐雷记系列任务中的四组镇石-御币解谜
## 问题
要令镇石再次作用、雷暴再次被镇压的话，就需要先找到并接触镇石对应的三组御币。应当谨记御币的所在位置与纸垂的面数。

镇石附有纸垂，由上下部分组成，各自可以转动。

转动镇石，使镇石上面向御币方向的纸垂面数，与御币上的纸垂面数对齐。当一座镇石与其所有对应的御币的纸垂面数都一一对应无误时，这座镇石的封印就巩固了。
### 分析
定义镇石上/下侧的转动次数为i/j(i,j∈N,0≤i<m,0≤j<n)，镇石上/下侧面向御币方向的纸垂面数为A/B(A,B∈N*)，有离散函数A=α(i)和B=β(j)；

又定义k为御币的位置，W为御币对应的纸垂面数，有离散函数W=ω(k)，其中W∈N*,k∈N；

则可定义函数f(x,y)=α(x mod m)+β(y mod n);

求证：存在一组(x,y)使得对任意k，有f[α(x+k),β(y+k)]=ω(k)。

### 算法
我们有三个数组alpha，beta，omega，其中alpha为镇石上半部分的纸垂数量，beta为镇石下半部分的纸垂数量，omega为三个御币的纸垂数量。

以清籁逐雷记·其四中的解谜为例：

镇石上半部分的纸垂数量为3,1,2,1,2,3；镇石下半部分的纸垂数量为1,1,2,3,1,2；三个御币的位置为0,1,4。

则得出以下数据：

alpha=[3,1,2,1,2,3]，beta=[1,1,2,3,1,2]，omega为[4,4,4]，m=n=6，k=[0,1,4]

|alpha|||||||
|----|----|----|----|----|----|----|
|i|0|1|2|3|4|5|
|A|3|1|2|1|2|1|

|beta|||||||
|----|----|----|----|----|----|----|
|i|0|1|2|3|4|5|
|B|1|1|2|3|1|2|

|omega|||||||
|----|----|----|----|----|----|----|
|k|0|1|4|
|W|4|4|4|

现在需要寻找一组(x,y)使得f[α(x+0),β(y+0)]=f[α(x+1),β(y+1)]=f[α(x+4),β(y+4)]=4。

显然可以通过二重循环遍历解空间。

## 时空复杂度分析
时间复杂度：O(m*n)

空间复杂度：O（m+n）
